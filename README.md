# SimasTelas 🏳️‍🌈

Transmissão de tela no navegador — até 1080p a 60fps com áudio estéreo em alta qualidade.
Feito pra usar no servidor do Discord: quem transmite copia o link e cola no chat; quem assiste só abre.

- Conexão direta entre navegadores (WebRTC via PeerJS), sem servidor próprio.
- Funciona melhor no Chrome/Edge. Marque "Compartilhar áudio" pra mandar o som.
- Link de quem assiste: `?sala=CODIGO`. O código fica salvo, então o link é sempre o mesmo.
